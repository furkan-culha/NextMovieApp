# 🎬 MovieApp

Modern bir **Next.js 16** film keşif uygulaması. TMDB API üzerinden popüler, son çıkan ve arama sonuçlarını listeler. Turbopack, App Router, TailwindCSS ve server component mimarisi ile geliştirilmiştir.

---

## 🚀 Özellikler

- 🔍 **Arama** özelliği ile film aratma
- 🎞️ **Popüler**, **En Son** ve **Yakında** gelen filmleri listeleme
- ⚡ **Next.js 16 App Router** mimarisi
- 🎨 **TailwindCSS** ile modern UI
- 🧩 Component bazlı temiz mimari
- 🌙 Hızlı geliştirme deneyimi (Turbopack)
